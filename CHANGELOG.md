## [0.1.0] - 2026-10-06

### Features

- Initial release of `findfmt`: Content-aware and `.gitignore`-conscious file discovery and
  classification suite.
- Integrated `identify` engine for deep content and extension inspection.
- Shebang-based interpreter detection and filtering (`--shebang`).
- MIME tag association and filtering.
- Hierarchical `.gitignore` and `.git/info/exclude` early-path pruning.
- NUL-delimited output (`-0`) for clean `xargs` pipeline integration.
- Formatted tag inspection (`-l, --list-tags`) and summary reporting (`-s, --summary`).
- 100% test coverage and pedantic type checking with `ty`.
