# Support Guide

Thank you for using `findfmt`! Here is how to get help and support:

## 1. Documentation

Comprehensive documentation is available at
[https://bdperkin.github.io/findfmt](https://bdperkin.github.io/findfmt).

## 2. Bug Reports and Feature Requests

Please search existing issues before creating a new report:

- [Search Issues](https://github.com/bdperkin/findfmt/issues)
- [Open a New Issue](https://github.com/bdperkin/findfmt/issues/new/choose)

## 3. Security Issues

For security vulnerabilities, please refer to our [Security Policy](SECURITY.md) and use GitHub's
private reporting features.
